# Blinkit-Project
🛒 Blinkit Sales Dashboard 📊
A Power BI dashboard project that visualizes and analyzes key business metrics of Blinkit (formerly Grofers), designed to provide deep insights into sales, 
customer behavior, and performance trends. This project showcases skills in data cleaning, data modeling, KPI design, and interactive report building.

📌 Project Overview
The Blinkit Sales Dashboard aims to:

Track and analyze sales, orders, profits, and shipping performance.

Visualize performance by category, subcategory, state, and payment methods.

Provide a forecast of future sales trends.

Deliver interactive filtering for better decision-making.

📂 Features
✅ Clean and organized dataset
✅ User-friendly and interactive dashboard
✅ Dynamic visuals for key KPIs
✅ Drill-down insights by product categories and regions
✅ Forecasting using Power BI's built-in analytics
✅ Easy-to-understand layout

🔧 Tools & Technologies Used
Microsoft Power BI – For data visualization and dashboard creation

Microsoft Excel – For data cleaning and preprocessing

DAX (Data Analysis Expressions) – For calculated columns, measures, and KPIs

📈 Key Visuals
Sales, Profit, Orders KPIs

Monthly Sales & Profit Trends

Sales by Category/Subcategory

Sales by State (Map Visual)

Payment Method Distribution

Forecasted Sales using Time Series Analysis

Returns Analysis (Binary: 0 - No Return, 1 - Returned)
